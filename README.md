# SolidCAM STL Exporter for SOLIDWORKS

Downloads of the SOLIDWORKS add-in that exports machine simulation STL files for SolidCAM.

**Install:** download the latest zip from the `releases` folder, unzip it to a permanent folder (for example `C:\Tools\SolidCamStlExporter`), close SOLIDWORKS, right-click `install.cmd` and choose **Run as administrator**.

After that, the add-in offers new versions automatically.

`latest.xml` tells the add-in which version is current. Do not rename or move it.
